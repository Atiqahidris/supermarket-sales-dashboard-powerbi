# Supermarket Sales Dashboard using Power BI

## 📌 Project Overview

This project presents an interactive Power BI dashboard developed to analyze supermarket sales performance using a public dataset. The dashboard provides business insights through data visualization, enabling users to monitor sales trends, product performance, and geographical sales distribution.

## 🎯 Objectives

* Analyze supermarket sales performance.
* Identify top-performing product lines.
* Monitor monthly sales trends.
* Compare sales performance across different cities.
* Visualize key business metrics to support decision-making.

## 📊 Dataset

* **Dataset:** `supermarket_sales_cleaned.csv`
* **Source:** Public dataset for learning and data analytics practice.

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* Data Visualization

## 🧹 Data Preparation

The dataset was prepared using Power Query by:

* Checking for missing values.
* Removing duplicate records.
* Formatting data types.
* Preparing the dataset for dashboard visualization.

## 📈 Dashboard Features

The dashboard includes:

* **Bar Chart** – Total Sales by Product Line
* **Pie Chart** – Sales Distribution by Product Line
* **Line Chart** – Monthly Sales Trend
* **Map** – Total Sales by City
* **Scatter Plot** – Gross Income vs Total Sales

## 🔍 Key Findings

* Identified the highest-performing product lines based on total sales.
* Compared sales performance across different cities.
* Observed monthly sales trends and seasonal patterns.
* Analyzed the relationship between gross income and total sales using scatter plot visualization.
